EU4 Menu Patch v0.1.0-experimental
EU4 1.37.5.0 Inca / Windows x64

点击 Back 或 Exit to Menu 时直接返回主菜单。
需要游戏目录中已有 Matanki EU4dll 的 VERSION.dll 加载器。
加载器项目：https://github.com/matanki-saito/EU4dll

安装
1. 保存战役并完全退出游戏。
2. 将 ZIP 中的 plugins 文件夹复制到 eu4.exe 所在目录，合并同名文件夹。
3. 正常启动游戏。更新时覆盖 plugins/eu4_menu_patch.dll。

补丁文件应位于：游戏目录/plugins/eu4_menu_patch.dll
安装不需要运行脚本。补丁在游戏启动后修改内存中的菜单切换逻辑。

卸载
退出游戏，删除 plugins/eu4_menu_patch.dll。

排查问题
查看 plugins/eu4_menu_patch.log，正常加载时包含：
menu transition patch initialized; author=VulonLok
出现 REFUSED 表示补丁未应用；没有日志时检查文件位置和加载器。

实验版已验证单人、非铁人，以及 MEIOU 与四个附属模组的测试组合：
选择国家界面的 Back，连续两局推进到下个月后返回主菜单。
铁人、多人、长期战役和其他模组组合尚未验证。
